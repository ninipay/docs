title: "Set your display preferences"
description: "Appearance changes how Nini looks for you."
---

Use it to make the screen comfortable to read before working through detailed records. These are personal display controls.

<Tip>
**Example:** Choose System if you want Nini to follow your computer's light or dark setting, or use Compact view to reduce spacing.
</Tip>

<Info>
**Before you start:** Be signed in. The Appearance page says that changes save automatically, so there is no separate Save step. Your choices are stored in the browser you are using, so set them again if you switch computers or browsers.
</Info>

## Step by step

1. Click Settings at the bottom of the sidebar, then Appearance under You.
2. Under Theme, choose Light, Dark or System. System follows the colour scheme selected in your operating system.
3. Use Compact view if you prefer tighter spacing and pages centred at a comfortable width. Turn it off if you prefer more room between items.
4. Turn on Ambient background if you want glow orbs and a dot pattern behind the app in dark mode. It is off unless you turn it on.
5. Under Sidebar colour, choose Default or Chromatic. Chromatic tints the frame with Nini's brand colours.
6. Return to a page such as Records and check whether the layout is comfortable. You can return to Appearance and change the same option again. Your name at the bottom of the sidebar opens an account menu with Theme (Light, Dark or Match system) and Compact view shortcuts.

<Check>
**Expected result:** You know where to change the display and that these choices save automatically.
</Check>

<Warning>
**If you get stuck:** If the system looks different from Light or Dark, check your computer's current theme. If you cannot see the ambient effect, check whether dark mode is active. If your choices reset, check whether you are using a different browser or have cleared its site data.
</Warning>
