---
title: "Find an uploaded or imported document"
description: "Documents holds original files and their review states."
---

Use it when you need to read an invoice, receipt or statement, or check what Nini read from it.

<Tip>
**Example:** You uploaded an August statement in September. The list shows both the Document date printed on the file and when it was Uploaded, so you can find it either way.
</Tip>

<Info>
**Before you start:** Have part of the filename, the party or an approximate date. The destination describes how Nini uses the file; the status describes where it is in the review process.
</Info>

## Step by step

1. Click Documents in the sidebar.
2. Check the destination switch beside the page title. Choose For your books for files that go into your books, or For Gia to read for files Gia reads without adding them to your books.
3. Look at Needs you for files waiting for your check, and Recent uploads for the latest files. If the other destination also has files waiting, the page tells you.
4. Under All documents, use Needs a check, Done or Couldn't read to narrow the list. Filters adds more statuses, such as Reading, Already uploaded, Not used and Removed, and lets you filter by type.
5. Check the date range and any other active filters. Find the file by its name, party, Document date or Uploaded date; click a column heading to sort by it.
6. Click the row to open the file in a panel beside the list, then follow [Review information extracted from a document](/guides/documents/review-extracted-information). Use Copy link in the panel to share the document with a colleague who has access.

<Check>
**Expected result:** You have found the original file and can inspect what Nini read from it.
</Check>

<Warning>
**If you get stuck:** If the file is missing, check the organization, destination, dates and status first. A file still Reading cannot be opened yet; check back in a minute. If it shows Couldn't read, record the message shown and use Try reading again before uploading another copy.
</Warning>

<Note>
A Needs a check status is a review signal. It is not proof that the underlying amounts are wrong.
</Note>
