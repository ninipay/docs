# Documentation project instructions

- This is the Mintlify site for docs.nini.io. Pages are MDX files with YAML frontmatter; configuration and navigation live in `docs.json`.
- Every new page must be added to the navigation in `docs.json`.
- `api-reference/openapi-partner.json` mirrors the ingestion API partner contract in the main repo. Update it only from that source.
- Use active voice, second person, sentence-case headings, and bold for UI elements.
- Never document internal admin, Fleet Ops, or unreleased features.
